# 学习内容配图需求统计

> 审查对象：`build/domains.json`（v2.1.0，8 域 / 29 块 / 170 条 / 888 段原文）；书库 32 部。审查日期：2026-11-14。
> 本文为只读审查，未改动工作台任何页面或数据。逐条判定由 `tools/illustration_audit.py` 生成，可复现。

## 一、一句话结论

**170 条学习内容里，139 条（81.8%）的课后任务有明确作图/制表指令（「画一张」「做一张表」「列四行」「画流程线」等），另有 14 条含可视化线索，合计 153 条（90.0%）；而工作台目前教学插图为 0 张。**
统计口径：只认明确指名图/表/卡/坐标/流程的指令，不把「表里」「表现」这类含「表」字的普通词算进来。

这不是「可以加点图锦上添花」，而是课程设计里已经把绘图当成了主要学习方法，却没有提供任何底图、模板或答案图。最需要补的是**脉诊与望诊的形态/空间图**，以及一批可复用的母图。

## 三、评级口径

| 级别 | 定义 | 建议交付 |
|---|---|---|
| **P0 必需** | 形态、颜色、空间位置、动态波形、多节点流程——文字无法替代，不配图容易学错 | 认知型插图，正文内直接呈现 |
| **P1 建议** | 课后任务已明确要求作图/制表，标准答案有校核价值 | 空白模板 + **折叠**的标准答案图 |
| **P2 可选** | 文字与表格已够用，配图收益有限 | 可打印表格模板（可选） |
| **P3 不宜** | 训诂、版本校读、写作方法等纯文字思辨 | 不配图 |

**一个重要判断：不能把学员要自己画的图全部提前画好。** 这套课的课后任务刻意用「闭卷默画 / 自己列表」做主动回忆，直接把成品图摆在正文里会破坏这个设计。P1 的正确做法是给空白模板（可打印/可交互填写）+ 折叠的答案图，学员做完再展开对照；P0 才是应该在正文里直接给的认知型插图。

## 七、原文里天然适合配图的语料

888 段原文中，**19 段（2.1%）含具象比喻**（如「和柔相离，如鸡践地」「上焦如雾，中焦如沤，下焦如渎」「如三菽之重」一类脉形与气化描写），**69 段（7.8%）直接描述可观察的形态/颜色/指下手感**（舌、苔、面色、肥瘦、举按寻）。这些段落是配图最自然的锚点，图片可以直接挂在对应原文卡片旁边。

样例：

- `1-11` 《灵枢·营卫生会》：上焦如雾，中焦如沤，下焦如渎。
- `1-25` 《素问·平人气象论》：平脾脉来，和柔相离，如鸡践地，曰脾平。
- `2-4` 《素问·脉要精微论》：声如从室中言，是中气之湿也。
- `2-9` 《诊家枢要·五脏平脉》：肺合皮毛，如三菽之重……肝合筋，如十二菽之重……脾合肌肉，如九菽之重……肾合骨，按至骨上而得者为沉。
- `4-3` 《伤寒论》桂枝汤方后注：温覆令一时许，遍身漐漐微似有汗者益佳，不可令如水流漓，病必不除。
- `4-19` 《神农本草经》丹参条：主心腹邪气，肠鸣幽幽如走水，寒热积聚，破癥除瘕，止烦满，益气。
- `4-22` 《神农本草经》桔梗条：主胸胁痛如刀刺，腹满肠鸣幽幽，惊恐悸气。
- `6-34` 《金匮要略·血痹虚劳病脉证并治》：血痹阴阳俱微，寸口关上微，尺中小紧，外证身体不仁，如风痹状，黄芪桂枝五物汤主之。

## 九、技术与安全约束

- **优先内联 SVG**，与现有「纯静态、无外部依赖」一致；避免新增图片请求与 CDN。
- **不要用真实舌象/面色照片**：涉及患者肖像与版权，且个体差异常被误当成标准。用标准化彩绘示意 + 明确标注「示意，非诊断依据」。
- **脉象波形是概念示意，不是真实脉搏波**：图上要写「示意」，避免学员把示意图当作波形诊断标准。
- 药材饮片照片本轮**不建议**补：这套课教的是药性与方证，不是中药鉴定，配饮片图会跑偏（本草域 30 条因此多数只判 P1/P2）。
- 每张图加 `alt` 文本与「图源/自绘」标注；折叠答案图默认收起，不破坏闭卷默画。
- 外部 178 MB 素材包须先做版权与相关性核查，不直接引用。
