# 日课册 · 视觉与界面规范

这是 `v2.html` 的设计说明。1.x 的 `index.html` 不动，两版并行，可随时对照。

## 一、主张

这个工作台不是「课程 App」，是**一册日课登记簿**。

168 天里有 168 次「第 N 天」的自我登记。所以界面的组织单位不是卡片，是**纸面、界行、印**：一张纸压在深色桌面上，竖排目录在左边，每天的内容像刻本一样按界行分栏，完成与未完成用「盖墨块 / 留空栏」表示，而不是彩色圆角卡片。

风格来自两处真实材料：**民国中医函授讲义的排版纪律**（竖排目录、界行分栏、字距拉开的小标签、朱笔批注）和**现代数据表的密度**（168 行课表、14 格登记条、等宽数字）。

刻意不做的：毛笔、水墨、宣纸纹理、印章图片、竹叶。这些是「中医 = 古风」的现成符号，和这个产品真正的活动——每天读 45 分钟原文再做四道题——没有关系。

## 二、配色

| 名称 | 色值 | 角色 |
|---|---|---|
| 松烟 | `#14211E` | 桌面。整页底色，只在纸面之外出现 |
| 素纸 | `#F7F4EA` | 纸面。所有内容的承托 |
| 纸背 | `#FCFAF3` | 纸面上唯一的抬升面（动手任务块、按钮） |
| 墨 | `#1B211D` | 正文、标题、已完成格 |
| 墨·次 | `#4A534D` | 解释层、白话、元信息正文 |
| 墨·三 | `#6E766F` | 标签、日期、天次、未启用的行 |
| 界 | `rgba(27,33,29,.16)` | 发丝分隔线 |
| 界·重 | `rgba(27,33,29,.34)` | 分节线、字段线 |
| 石青 | `#1D4E63` | 出处、引用、导航激活、正确项 |
| 朱 | `#9E2B23` | 只有三处：今日、错题、红线 |
| 赭 | `#8A5A24` | 有记录但未达标 |

规则只有一条：**朱色不做填充按钮，不做装饰，只标「这里需要注意」**。纸是暖的，桌面是冷的深墨绿——暖调不会被整页包裹成「奶油底」。

对比度：正文 13.9∶1，墨·三 4.6∶1，朱 6.8∶1，石青 8.3∶1，赭 5.4∶1。全部达到 WCAG AA。

## 三、字体

两族，各管一层：

**宋体**（`Songti SC / Source Han Serif SC / SimSun / Georgia`）
- 原文 17–19px，行高 2.05，字距 .045em，首行缩进 2 字符
- 节标题 21px / 600；课程标题 24–30px
- 天次数字 46–78px
- 印章、竖排目录

**黑体**（`PingFang SC / Microsoft YaHei / system-ui`）
- 白话、要点、解析、题干 14.5px，行高 1.85
- 标签 10.5–12px，字距 .18–.24em
- 按钮、元信息

分工是内容驱动的：**原文用刻本的字体，解释用现代的字体**，一眼能分出哪句是古人说的、哪句是课程说的。

数字全部 `font-variant-numeric: tabular-nums`，168 行课表的时长纵向对得齐。

不引外链字体，离线可用；中文走系统字体栈，不加载任何网络资源。

- 纸面最大 1180px，桌面留白 26/20px；≤820px 纸面满屏、无边框
- 页边 `clamp(20px, 4vw, 56px)`
- 阅读列定 620px（原文约 31 字/行）；旁批列 280px，中间 88px 空白栏，形成书页的天头地脚
- 学情检查、本周、课表统一收在 660px 的登记列里，右侧留白不塞东西
- 分节只用发丝线，节标题 21px ＋ 前置 5px 朱方块（这是全页唯一的装饰性色块）

## 五、组件

**天头**：引题 11.5px 拉开字距 → 天次 46–78px → 日期行 → 三格数字（`border-left` 发丝线分隔）。右上角朱框印章「日課」，旋转 -2.2°。

**原文段**：左侧 1px 界线，出处 11.5px 石青，原文宋体缩进 2 字符，`白话`／`校读` 用小标签起头。校读换 1px 朱线，表示「这是批注，不是原文」。

**要点**：一二三四中文序号（避开选项的甲乙丙丁），每行一条发丝线，像账簿。

**练习**：选项是 44px 高的整行按钮，甲乙丙丁标号；单选点击即判分，多选点「交卷」。判分后正确项染石青、错选染朱、解析展开在界线下。答完四题即记入今日，出现一条朱线提示。

**登记条**：14 格，一格一天；完成＝墨块反白，未达标＝赭色数字，没记录＝空栏破折号；今天那格加 3px 朱底边并写「今日」；≤640px 拆成 7×2。

**课表**：`<details>` 按阶段折叠，表头左侧竖排「阶段一」＋ `+ / −` 标记；行是「天次／标题／时长」三列，已上的天次染石青、今天染朱、未到的压灰且不可点。已过的天可点，回到阅读列重看，顶部有一条「回看·不计入今日」的说明条。

**旁批列**：`position:sticky`，两段——红线四条（不开方／不荐药／不记剂量／不扎针）与今日进度。红线常驻可见是产品要求，不是装饰。

## 六、动效

一次编排好的入场：天头、五个分节、地脚依次 60ms 淡入上浮 9px，总计 380ms。除此之外没有散射式 hover 动效；`hover` 只改底色或字色，`transition` 全是 180ms 的 `ease`。

`prefers-reduced-motion: reduce` 下全部关闭。

## 七、可访问性

- 全部可点元素是 `<button>` / `<a>` / `<summary>`；课表行补 `tabindex="0" role="button"` 并响应 Enter / 空格
- `:focus-visible` 统一 2px 石青描边、3px 偏移
- 正文对比度 ≥ 4.6∶1，全部 AA
- 语义：`<header>` `<main>` `<section>` `<article>` `<figure>/<blockquote>` `<details>/<summary>` `<dl>`
- 无图片、无外链资源、无追踪；数据只写 localStorage，读写都包在 try/catch 里，file:// 下也能跑
- 320px 宽仍无横向溢出

## 八、与 1.x 的差别

| | 1.x（index.html） | 2.0（v2.html） |
|---|---|---|
| 结构 | 圆角白卡 + 阴影，12 列网格 | 纸面 + 界行，单列登记 |
| 分类 | 四色标签（绿橙蓝紫） | 只用墨／石青／朱／赭四义 |
| 标题 | Georgia + PingFang | 宋体 + 黑体分层 |
| 课表 | 彩色格块 | 折叠的分阶段登记表 |
| 打卡 | 圆角色块 | 14 格台账，完成＝墨块 |
| 导航 | 顶部横条（锚点） | 左侧竖排目录（滚动跟随） |

内容、数据、解锁规则、判分逻辑完全沿用 1.3.0：168 天、543 段原文、672 道题，一字未改。
