## 一、v2.1：你后来提的四点，逐条对应

**1. 「每节课后面的习题要按照之前规定，都是 6+1」**

v2.0 重构时新写的条目只有 3 道单选、没有综合题，旧课则是 6 道题但题型混杂。现在 **170 条一律 6 道基础题 + 1 组综合辨析**（材料 + 4 个子判断）。补齐用固定的伪随机种子，答案位置打散，不会总在 A，也不会每次构建都变。

顺带修了一个旧毛病：旧课里有 126 道**多选题**（答案是数组），v2.0 的判分只按单值比较、选项也只允许单选，导致这些题永远判错。现在多选题可以多选、再点一次取消，按「选全且不多选」判分，题头会写明「含多选，多选须选全」。

**2. 「筑基部分要把《中医基础理论》讲一遍，加大篇幅」**

v2.0 为了尽早进诊断，把筑基压成 7 讲的最小骨架。v2.1 按你的要求重写为 **「中基筑基」5 块 25 条**，按教材章节全程走一遍：

## 二、v2.0：最初那三点

**「知识点零零散散的非常难受」**

旧版把知识按天切成 168 份，同一条线被拆到好几天里。比如脉诊散在六天中，学完看不出「脉诊」整体长什么样。这不是内容不够，是切法的问题。

新版改成 **域 → 知识块 → 条目**：一个知识块就是一个完整主题（如「脉诊 · 精读《诊家枢要》」），块内按「总纲 → 分支 → 对比 → 原文 → 自测」排成一个体系。原本散在各天的同主题内容归并到同一块，一次能读通。现在是 8 个域、29 块、170 条。

**「不设每天学习的上限」**

旧版的进度是「第几天」，今天该学什么由日期决定。新版彻底删掉了「天」：

- 没有「今日课程」、没有开始日、没有逐日解锁、没有「明天再来」。
- 只有「这条学完了」的勾选；进度 = 已完成条目 / 170，按域、按块分别显示。
- 一天看完一块或连看三块都行，学得快不用等，停下来也不会掉队。
- 自测判分只用于自查，不设通过线、不卡进度。

**「早点进入诊断方面的学习」**

旧版诊断排在 D40 之后，得先学 39 天阴阳五行藏象。新版把顺序倒过来：

1. **中基筑基**（v2.1 起 25 条，按《中医基础理论》全程）：可以按顺序读，也可以只在遇到不懂时回查。
2. **四诊 · 望闻问切**（15 条）：望、闻、问各一块，**脉诊单独成块、8 讲**，直接以你手上那本《诊家枢要》为骨架。
3. 之后再是辨证、本草、方剂、经典、临证、专题。

也就是说，翻过筑基就能进诊断，且第一本书就是正在读的那本。

## 三、顺带补上的两件事

**书库补了《诊家枢要》**。旧书库 31 部里只有《脉经》《濒湖脉学》，滑寿这本书一个字都没有，你读的原文在工作台里查不到。现在全文（约 2.1 万字，含序、自序、20 篇正文、题跋）已入书库，点书名就能读，支持书内检索；标题旁点「译」还能读白话逐篇译解。

**发现你手上那三段是「三书节引合抄」**，值得单独说一下。对着底本逐句核过：

| 你那版的句子 | 实际出处 |
| --- | --- |
| 时脉谓：春三月，六部中俱带弦，夏带洪，秋带浮，冬带沉 | 《诊家枢要·持脉手法》（原文作「夏三月，俱带洪；秋三月，俱带浮；冬三月，俱带沉」，节引脱「三月」） |
| 按之，脉和柔相离，如鸡践地，曰平 | 《素问·平人气象论》：「平脾脉来，和柔相离，如鸡践地，曰脾平」，形容脾之平脉，**不是滑寿的话** |
| 肥人责浮，瘦人责沉……故责之 | **《伤寒论·平脉法》**：「师曰：脉，肥人责浮，瘦人责沉……」，张仲景语，比滑寿早约一千二百年，不是后世补充 |
| 臂短则疏密下指 | 通行本作「臂短则**密**下指」，脱一「臂」字、衍一「疏」字 |
| 四时之脉不相**度** | 通行本作「不相**戾**」（戾，违也） |
| 凡病之脉，见在上曰上病……以次推之 | 与《诊家枢要》原文基本一致，可放心作原文读 |

「责」是「求、追究」（方有执注：责，求也），不是责怪：肥人肌肤厚，脉本当沉，如今反浮，就要追问病在哪。

这些校读点已经写进脉诊块对应讲的「看这里」，`library/诊家枢要.txt` 末尾也附了完整的「常见节引校读」，可以直接对照着读。

## 四、怎么开始

打开工作台 → 点「四诊 · 望闻问切」→ 找「脉诊 · 精读《诊家枢要》」→ 从第一讲「脉为气血之先」开始。读到某句想核，就点原文卡片下的「在《X》中查看此段 →」跳回原书；想先弄清白话，就点书库标题旁的「译」。

想系统补骨架，就从第一域「中基筑基」按 1-1 顺读；不按顺序、遇到不懂再回去查也完全可以。

每读完一条，做完 6+1 自测、勾一下「已学完」即可。进度会自动存，换设备前在「我的」页导出一次备份。
