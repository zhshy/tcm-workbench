## 一、课程从哪来

按 `中医系统自学路线图.md` 的四阶段排课，正好走完 24 周：**168 天，每天一课**。阶段 1 是此前已交付的 49 天，这次补齐的是阶段 2–4 的 119 天。

| 阶段 | 天数 | 单元数 | 内容 |
| --- | --- | --- | --- |
| 1 骨架 | D01–D49 | 7 | 绪论与阴阳五行、藏象、气血津液、经络、病因病机、四诊、八纲 |
| 2 血肉 | D50–D105 | 16 | 中药总论与各类药、方剂总论与各类方、闭卷方解复盘 |
| 3 溯源 | D106–D147 | 11 | 伤寒论导读与六经条文、金匮选篇、内经选篇、温病条辨选读 |
| 4 输出 | D148–D168 | 5 | 四个专题 + 成文与自检 |

合计 **40 个单元**，课表按单元分组显示，每组标出起止天次与完成数。

## 二、每课结构（固定六块）

1. **本课目标**：一句话，可验收。
2. **经典原文**：3–4 段，每段四层——原文（衬线）/ 出处 / 白话 / 看这里（句读、训诂、异文提示）。
3. **课程要点**：4–5 条，写成能复述的话。
4. **动手任务**：5–8 分钟能做完，必须产出东西（卡片、对照表、待核清单）。
5. **对照阅读**：具体到教材章节或古籍篇目。
6. **今日主句**：一句原文 + 出处，作为这一天的记忆锚点。

## 三、数据规模

| 项目 | 数量 |
| --- | --- |
| 天数 | 168 |
| 经典原文段 | 543 |
| 原文 + 白话 + 提示总字数 | 约 5.4 万字 |

| 日均 | 45.7 分钟 |

时长按原文段数定：3 段 45 分钟（129 天），4 段 48 分钟（39 天）。页面顶部按 55% / 17% / 13% / 15% 派生配速：原文 24′、要点 8′、任务 6′、练习 7′。

## 四、练习与判分

- 每天 4 题：单选 2、多选 1、判断 1，全部客观题。
- 提交前不给答案；提交后每题给「正确答案字母 + 解析」，解析里说明错误项错在哪。
- 多选必须完全匹配，漏选判错；可无限重做，成绩取最后一次，时长不重复叠加。

## 五、解锁与联动规则

- **开始日**：第一次打开 App 那天，存 `S.course.start`。面板底部有「把开始日改到今天」。
- **逐日解锁**：第 N 天只在「开始日 + N − 1」这天可点；未来日期是锁定态（虚线 + 浅字 + `disabled`），点了不切页。最后一天 D168 也遵守同一规则。
- **完成判定**：提交练习才算完成一天，返回课表该格变浅绿并显示成绩。
- **计入学习**：完成一课把该课时长（45 或 48 分钟 × 60 秒）以「取较大值」方式写入当日学习时长。
- **学情检查**：完成即调 `ensureCheck()` 生成 D+3～D+5 的检查窗，题目仍全部客观题。

## 六、内容边界

- 课程全程定位**文本层**：读原文、辨术语、对证方，不做诊断，不给处方与剂量。
- 中药与方剂部分只写性味归经、功效主治、君臣佐使与主治证，**不写剂量**，不给服用建议。
- 十八反、十九畏、妊娠禁忌只作知识记录并标注「不用于自行用药」。
- 阶段 3、4 的异文一律写明「待核宋本与桂林古本」，不编造异文；不确定条号时只写篇名。
- 任何身体不适请就医，App 里的内容不构成诊疗依据。

## 七、数据与工程

- 课程数据内嵌为 `var COURSE = [...]` 与 `window.RD = {...}` 两段，位于主脚本 IIFE 之前，共约 256 KB。
- 界面逻辑独立成段（`cHomeHTML` / `cCourseHTML` / `cQuizHTML` / `cJudge` / `cFinish`），挂在 `renderAll()` 与 `renderToday()` 里。
- 构建脚本从模板重建，可重复执行；合并脚本按 168 天做全量校验后才生成数据。
- 校验：168 天序号连续、543 段原文齐全、答案索引合法、无同单元重复原文、无剂量表述、无脚本注入字符。
- 测试：无头浏览器 62 项断言全部通过；390 / 360 / 320 三档宽度零横向溢出。

## 八、已知取舍

1. **阶段 2 与阶段 3 会出现同一批条文**：方剂课用条文讲方，校读课再逐字读同一条，这是有意的「螺旋重复」，不是数据重复（跨单元重复 95 段，同单元内为 0）。
2. **脉诊只到概念层**：没有实操训练条件，课上只讲脉象术语与主病对应，不教把脉。
3. **96 天旧版**：GitHub 仓库里保留为 `v1-96天版.html`，入口页已换成 168 天版本。
