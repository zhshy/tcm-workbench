# 工作台「每日课程」说明（168 天完整版）

> 产出：`index.html`（单文件，约 1.1 MB，零依赖，双击即用；进度存在浏览器 localStorage）
> 在线版：https://zhshy.github.io/tcm-workbench/
> 更新日期：2026-11-13

> **当前实现基线（v1.4.0）**：每天 6 道基础客观题 + 1 道综合客观大题（含 4 个客观子判断），10 个计分点、70% 为日课通过线；所有题目自动判分，不设置必做主观题。计划用时 50–55 分钟，实际专注时间单独计时。

按 `中医系统自学路线图.md` 的四阶段排课，正好走完 24 周：**168 天，每天一课**。阶段 1 是此前已交付的 49 天，这次补齐的是阶段 2–4 的 119 天。

| 阶段 | 天数 | 单元数 | 内容 |
| --- | --- | --- | --- |
| 1 骨架 | D01–D49 | 7 | 绪论与阴阳五行、藏象、气血津液、经络、病因病机、四诊、八纲 |
| 2 血肉 | D50–D105 | 16 | 中药总论与各类药、方剂总论与各类方、闭卷方解复盘 |

合计 **40 个单元**，课表按单元分组显示，每组标出起止天次与完成数。

## 二、每课结构（固定六块）

1. **本课目标**：一句话，可验收。
2. **经典原文**：3–4 段，每段四层——原文（衬线）/ 出处 / 白话 / 看这里（句读、训诂、异文提示）。
3. **课程要点**：4–5 条，写成能复述的话。
4. **动手任务**：5–8 分钟能做完，必须产出东西（卡片、对照表、待核清单）。
5. **对照阅读**：具体到教材章节或古籍篇目。
6. **今日主句**：一句原文 + 出处，作为这一天的记忆锚点。

## 四、练习与判分

- 每天 6 道基础客观题 + 1 道综合客观大题；综合大题以本课目标和要点作为共同材料，含 4 个“候选答案是否成立”的客观子判断。
- 每日总分 10 分：6 道基础题各 1 分，综合题 4 个子判断各 1 分；综合题按子题给分，可部分得分，不设负分。
- 单选、判断按标准答案判分；多选必须完全匹配，漏选判错；日课得分达到 70% 记为通过。
- 提交前不显示答案；提交后显示正确答案、解析及来源核验状态。来源未核验的题明确提示待核，不自动编造出处。

## 五、解锁与联动规则

- **开始日**：第一次打开 App 那天，存 `S.course.start`。面板底部有「把开始日改到今天」。
- **逐日解锁**：第 N 天只在「开始日 + N − 1」这天可点；未来日期是锁定态（虚线 + 浅字 + `disabled`），点了不切页。最后一天 D168 也遵守同一规则。
- **完成判定**：首次提交即记为完成；达到 70% 另记为通过。完成、通过和长期掌握是不同状态，单次通过不代表长期掌握。
- **答题历史**：保留首次完成日期、最近成绩、最佳成绩、尝试次数及最近 20 次完整作答；重做不会覆盖首次记录。
- **计入学习**：计划课程分钟不计入实际专注时间。课程页可主动启动/暂停计时器；旧版自动折算分钟迁移到 `legacy_estimated_sec`，保留但不再冒充实际时长。
- **草稿与复习**：未提交答案自动保存在本地；答错题按知识点安排 D+1、D+3、D+14、D+30 复习提示。
- **学情检查**：完成课程提交后生成 D+3～D+5 的检查窗，不再依赖伪造的 20 分钟时长门槛。

## 七、内容边界

- 课程全程定位**文本层**：读原文、辨术语、对证方，不做诊断，不给处方与剂量。
- 中药与方剂部分只写性味归经、功效主治、君臣佐使与主治证，**不写剂量**，不给服用建议。
- 十八反、十九畏、妊娠禁忌只作知识记录并标注「不用于自行用药」。
- 阶段 3、4 的异文一律写明「待核宋本与桂林古本」，不编造异文；不确定条号时只写篇名。
- 任何身体不适请就医，App 里的内容不构成诊疗依据。

## 八、数据与工程

- 课程数据内嵌为 `var COURSE = [...]` 与 `window.RD = {...}` 两段，位于主脚本 IIFE 之前，共约 256 KB。
- 界面逻辑独立成段（`cHomeHTML` / `cCourseHTML` / `cQuizHTML` / `cJudge` / `cFinish`），挂在 `renderAll()` 里；首页三块由 `renderHeat()` / `renderWeekFocus()` / `renderTodayCourse()` 负责，`renderToday()` 只做调用与顶栏两个指标。
- 构建脚本从模板重建，可重复执行；合并脚本按 168 天做全量校验后才生成数据。
- 校验：168 天连续；每天 6 道基础题；每课生成 1 道四子题综合大题；题目 ID 唯一；答案索引合法；来源状态和引用数组完整。
- 来源盘点：当前 1008 道基础题中，336 道带有课程引用索引，672 道标记为 `needs_manual_source_review`；未核验题目不自动补造出处，详见 `data/assessments/question-provenance-audit.json`。
- 可复现测试：`npm run validate`、`npm test`、`npm run test:python`；GitHub Actions 在 main 和 PR 自动运行。

## 九、已知取舍
