## 一、为什么改

v1.4.2 把知识按「天」切成 168 份，同一条知识线（如脉诊）散在六天里，学完看不出全貌；进度由日历决定；诊断排在 D40 之后，与实际阅读顺序脱节。v2.0 把驱动换掉：

- **组织单位**：域 → 知识块 → 条目。一个知识块是一个完整主题，块内按「总纲 → 分支 → 对比 → 原文 → 自测」成体系。
- **进度模型**：只有「这条学完了」的勾选，没有「第几天」「今日课程」「逐日解锁」，也不设每日上限。一天看一块或连看三块都行。
- **顺序**：第一域是最短筑基，第二域直接进四诊，脉诊为重点。

## 三、条目结构

每条固定五块，与旧版一致但不再绑定日期：

1. **目标**：一句话，可验收。
2. **经典原文**：每段四层——原文（衬线体）/ 出处 / 白话 / 看这里（句读、训诂、异文、校读提示）。
3. **要点**：4–5 条，写成能复述的话。
4. **动手任务**：5–8 分钟能产出东西（卡片、对照表、待核清单）。
5. **自测**：随条小测，勾选即记「已学完」，不计分、不设通过线。

## 四、脉诊块与《诊家枢要》

四诊域单列「脉诊 · 精读《诊家枢要》」一块，8 讲顺序为：脉为气血之先 → 寸口六部 → 五脏平脉与菽重 → 时脉与体质 → 指法 → 六脉提纲 → 病脉定位 → 脉贵有神。每讲以滑寿原文为骨架，对照《脉经》《濒湖脉学》，并标出与读者手上版本的异文。

书库已补入《诊家枢要》全文（21,495 字，早稻田藏天顺七年刻本整理本为底本，含序、自序、20 篇正文、题跋），末尾附「常见节引校读」：

- 读者手上第一段「时脉谓春三月……」是**三书节引合抄**：时脉句出《诊家枢要·持脉手法》，「和柔相离，如鸡践地」出《素问·平人气象论》，「肥人责浮，瘦人责沉」出《伤寒论·平脉法》（张仲景，早于滑寿约一千二百年，非后世补充）。
- 第二段「臂短则疏密下指」通行本作「臂短则密下指」（脱「臂」衍「疏」）；「四时之脉不相度」通行本作「不相戾」。
- 第三段病脉定位与《诊家枢要》原文基本一致，可放心作原文读。
