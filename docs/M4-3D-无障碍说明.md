# M4 五行 3D 交互 · 无障碍说明

适用范围：`#/gallery` 与条目页（如 `#/i/1-5`）里的「M4 五行生克制化乘侮环」3D 演示层。
实现位置：[app_template.html](../build/app_template.html)（结构、样式、加载与降级）、[wuxing3d.js](../assets/js/wuxing3d.js)（场景与交互）、[three.module.min.js](../assets/vendor/three.module.min.js)（本地 Three.js r160）。

3D 只是视觉增强层。**看不到画布、无法使用鼠标或 WebGL 不可用时，全部知识点仍可通过 DOM 文本、五个铜章按钮和「关系表」获取**；静态 webp 始终保留。

## 一、入口与降级

| 场景 | 行为 |
| --- | --- |
| 图谱页 M4 卡片 | 「3D 交互演示 · 可旋转 · 可推演」按钮，`<button type="button">` |
| 条目页图解（1-5 / 1-6 / 3-3 / 5-3 / 6-32 / 8-16） | 「3D 交互演示 →」按钮 |
| 浏览器不支持 WebGL | 不加载 Three.js；`toast`（`role="status"`、`aria-live="polite"`）提示「当前浏览器不支持 WebGL，已打开静态图」，并打开原 webp 灯箱 |
| 3D 模块加载失败 | 提示「3D 组件加载失败，已打开静态图」，回退到同一 webp |
| 层内「看静态图」 | 关闭 3D 层，打开 M4 静态 webp 灯箱（可用 Tab 到上一张 / 下一张 / 关闭） |
| 减少动态效果 | 不自动播放「沿生序」，按钮禁用并提示原因 |

降级不是隐藏功能，而是等价阅读路径：静态图 + 本讲正文 + 关系表。

## 二、键盘操作

打开后焦点进入 3D 层，初始落在右上角「关闭」按钮。Tab 只在层内首尾之间循环。

| 按键 | 作用 |
| --- | --- |
| `Tab` / `Shift+Tab` | 在关闭、看静态图、五个铜章、状态胶囊、常/太过/不及、关系表、条目链接、底部工具之间移动；首尾循环 |
| `Enter` / `Space` | 激活当前铜章或按钮（原生按钮行为） |
| `←` / `→` | 绕盘面左右旋转 |
| `↑` / `↓` | 俯仰视角（限制在 0.18–1.34 rad） |
| `+` / `=` | 拉近 |
| `-` | 拉远 |
| `Esc` | 关闭 3D 层，焦点回到打开前的元素 |

补充：

- 方向键与缩放由层根节点的 `keydown` 处理，焦点在任意按钮上时都可用；输入框内不拦截（本层没有输入框）。
- 鼠标双击复位只在指针设备上提供；键盘等价操作是底部「复位」。
- 空白处单击取消选择；键盘等价操作是「复位」，或再次激活同一铜章（常模式下）。

## 三、读屏与语义结构

- 容器：`role="dialog"`、`aria-modal="true"`、`aria-labelledby="wxTitle"`，标题为「五行生克制化乘侮环」。
- 五个铜章是原生按钮，`aria-label` 形如「木，肝、胆」，选中时 `aria-pressed="true"`；未选中元素只做视觉淡化，仍可聚焦、可读。
- 状态胶囊「常 / 木 · 常 / 木 · 太过 / 木 · 不及」是按钮，`aria-label` 与显示文本同步，形如「当前状态：木 · 太过，点击复位」；点击或回车等同复位。
- 病机三态是 `role="group" aria-label="病机状态"` 内的三个按钮，各自用 `aria-pressed` 表示当前态。
- 右侧面板使用标题、`dl`（志/味/色/季）、关系行；底部「关系表（读屏 / 打印）」是原生 `<table>`，带 `<caption>` 与 `th/td`，包含生我、我生、克我、我克、太过、不及六行。
- 选择或切换状态时，隐藏的 `role="status" aria-live="polite"` 区域（`#wxLive`）播报，例如：
  - 「已选择木。木生火，木克土。」
  - 「已选择木，太过。木乘土，木侮金。」
  - 「已选择木，不及。金乘木，土侮木。」
- 画布本身不承载语义，也不可聚焦；所有交互入口都在 DOM 中，读屏用户无需操作 canvas。

## 四、视觉编码与对比度

同一含义同时用**线型、粗细、方向、文字标签**表达，不依赖颜色单一通道：

| 关系 | 线条 | 辅助编码 |
| --- | --- | --- |
| 相生 | 金色实线圆弧，顺时针 | 粒子沿弧线流动；面板「生我 / 我生」 |
| 相克 | 暗金细线五角星 | 隔位相制；面板「克我 / 我克」 |
| 相乘 | 朱砂粗实线 + 箭头 | 线段中央「木乘土」等文字标签 |
| 相侮 | 青灰虚线 + 反向箭头 | 线段中央「木侮金」等文字标签 |

对比度按 sRGB 相对亮度计算（主背景 `#07101F`，面板 `#09132A`；同一颜色在两处的差异小于 0.5）：

| 用途 | 颜色 | 对比度 |
| --- | --- | --- |
| 主文本 | `#EDE6D6` | 15.31:1 |
| 铜章文字 | `#F0E6CF` | 15.35:1 |
| 金色标题/状态 | `#C8A15A` | 7.89:1 |
| 状态胶囊 | `#D9B878` | 10.04:1 |
| 条目链接 | `#9FC3E0` | 10.30:1 |
| 次级文本 60% | `#91908D` | 5.96:1 |
| 次要标签 / 说明 55%（关系行、属性 dt、表格 caption/th、免责小字） | `#868684` | 5.22:1 |

本次修订已把这些 10–11px 的次要文字统一从 `.42/.45/.5` 提升到 `.55`，面板背景上约 5.13:1，达到 WCAG AA 正文要求。

焦点样式：`2px solid #E8C98A`，外扩 2–4px；键盘焦点与悬停高亮一致。

## 五、动效与减少动态

- 默认没有自动旋转、没有自动巡演；粒子动画仅作方向提示。
- `prefers-reduced-motion: reduce` 时：
  - 「沿生序」禁用，`title` 说明「已开启减少动态效果」；
  - 已启动的巡演立即停止；
  - 生克/乘侮粒子固定在路径上的某个位置，不再移动（乘侮粒子取中点）。
- 系统设置在页面打开后切换也会生效（监听 `change`）。
- 「沿生序」为用户主动启动，可随时用同一按钮（文字变为「停止」）停止，不构成自动播放内容。

## 六、触摸与移动端

- 单指拖拽旋转，双指捏合缩放，点铜章选择，点空白取消。
- 没有仅靠悬停才能获得的信息；悬停只做临时高亮。
- 390×844 实测：文档宽度 390/390，无横向滚动；五个标签均在视口内；底栏工具完整可见。
- 窄屏下面板高度上限为 `36vh` 并可内部滚动；图例在 520px 以下隐藏，工具按钮保留。

## 七、焦点与状态

- 打开时记录 `document.activeElement`，关闭后恢复焦点。
- `Esc` 与 hash 路由变化都会关闭 3D 层，避免遮罩与页面状态不一致。
- 关闭时释放 geometry、material、renderer 与 DOM 标签，避免 WebGL 上下文泄漏。

## 八、已知限制与改进建议

1. **五个铜章没有方向键组内导航**，需要 Tab 逐个经过。若后续增加节点较多，建议采用 roving tabindex + 方向键。
2. **空间布局没有文字等价描述**：盲人用户通过关系表获得「生我/我生/克我/我克/太过/不及」，但不描述盘面几何位置；这是有意的等价替代，不是逐像素描述。
3. **`aria-modal` 之外未给背景加 `inert`**，部分读屏的虚拟光标仍可能移动到背景；建议在打开时给页面主体加 `inert`。
4. **减少动态下相机缓动仍保留**（约 0.1 的插值），移动幅度小但非瞬时；可在该模式下直接赋值相机目标。
5. **极小屏与 200% 文字缩放未覆盖**：本次验证到 390px；更窄时标签可能重叠。9–10px 的辅助小字在移动端偏小，可考虑增大。
6. 静态图灯箱本身支持 Tab 到上一张/下一张/关闭与 `Esc` 关闭，但没有左右方向键快捷键；这是既有灯箱行为，不属于 3D 层。

## 九、自测清单

1. **纯键盘**：Tab 到 M4 入口 → Enter → Tab 遍历五个铜章 → Enter 选择木 → 切到「太过」→ 确认面板出现「木乘土 / 木侮金」→ Esc 关闭，焦点回到入口。
2. **读屏**：VoiceOver（macOS `Cmd+F5`）打开层，确认对话框名称、五个铜章名称与按下状态、三态按钮、关系表表头；切换状态时听到 `#wxLive` 播报。
3. **减少动态**：系统开启「减弱动态效果」或 Chrome 使用 `--force-prefers-reduced-motion`，确认「沿生序」禁用、粒子静止。
4. **降级**：关闭硬件加速或使用 `--disable-gpu`，点击入口应看到 toast 并打开静态 webp。
5. **移动端**：390px 宽下确认无横向滚动、标签不被裁切、底栏按钮可点。
6. **打印**：打印预览中整个 3D 层隐藏，不占版面。

本次回归实测结果：桌面 1280×900 与移动 390×844 视觉正常；`木 · 太过 → 木乘土 / 木侮金`、`木 · 不及 → 金乘木 / 土侮木`、关系表 6 行、状态胶囊 `aria-label` 随选择更新、Esc 关闭、巡演首步「火」、hash 切换关闭、静态图灯箱、WebGL 回退 toast 均通过；次要文字对比度 ≥5.13:1；`python3 -m unittest` 4 项通过。
