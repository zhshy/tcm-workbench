# 中医学习工作台

一个给自己用的单页学习系统：六阶段路径、31 部公版古籍、可导出的学习卡片、以及一套「让 AI 查表而非凭记忆」的提问模板。

纯静态，无后端、无追踪、无外部依赖。所有个人数据只存在你自己浏览器的 localStorage 里。

## 在线使用

发布后地址：`https://<你的用户名>.github.io/tcm-workbench/`

### 装到手机主屏幕

- **iPhone / iPad（Safari）**：打开网址 → 分享 → 「添加到主屏幕」。之后从桌面图标进入，全屏无地址栏。
- **Android（Chrome）**：打开网址 → 右上角菜单 → 「安装应用」或「添加到主屏幕」。

### 手机和电脑的数据怎么同步

页面数据存在各设备浏览器本地，**不会自动互通**（这是静态页面的固有限制，也意味着没有服务器能看到你的笔记）。两种搬运方式：

1. **同步码**（推荐，手机上最方便）：「我的卡片 → 跨设备同步 → 生成同步码」，把这段文本发到微信/备忘录，在另一台设备粘贴后点「从同步码导入」。
2. **JSON 备份**：「我的卡片 → 导出备份」，得到文件后传到另一台设备，用「导入」还原。

导入会覆盖本机数据，操作前先导出备份。

## 页面结构

| 模块 | 内容 |
| --- | --- |
| 总览 · 今日 | 三件事打卡、连续天数、每日一读、最近卡片 |
| 学习路径 | 筑基 → 诊断 → 本草 → 方剂 → 经典 → 临证，含教材、目标、自测题 |
| 资源库 | 25 个已核实 star 的 GitHub 项目，按生态层级与学习阶段筛选 |
| 古籍资料库 | 31 部公有领域古籍，可在线阅读，约 18.5 MB |
| Skill 接入 | 5 个中医 Agent Skill 的安全审计结论、三种接入方式、安装命令 |
| 我的卡片 | 概念/辨证/药对/方证/条文/医案六类卡片，可搜索、筛选、导入导出 |
| 提问模板 | 12 条可直接复制的提问话术，含「学习契约」 |

## 关于内容边界

- **收录的古籍均为公有领域文本**（作者逝世已久，作品已进入公共领域）：黄帝内经、伤寒论、金匮要略、神农本草经、本草纲目、医宗金鉴、温病条辨等。
- **《中医基础理论》《中药学》七版《方剂学》七版等规划教材未收录**，因其仍在版权期内，不适合随公开仓库分发；这部分只保留在本地 `skills/` 目录。
- 本项目及所引开源项目**仅用于中医学习与古籍研读**，不构成诊断、处方、用药或剂量建议。身体不适请就诊于执业中医师。
- 古籍原文为电子化文本，可能存在 OCR 或传抄讹误；引用前请核对纸本或权威点校本。

## 本地开发

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

直接双击 `index.html` 也能用（`file://` 下卡片与进度正常，古籍链接指向本地文件亦可打开）。
