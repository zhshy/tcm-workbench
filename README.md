# 中医学习工作台

一个给自己用的单页学习系统：**168 天完整课程**（阶段 1–4，每天 45–48 分钟，543 段经典原文、672 道带答案的客观题）、31 部公版古籍、可导出的学习卡片，以及一套「让 AI 查表而非凭记忆」的提问模板。

纯静态、无后端、无追踪、无外部依赖。个人数据默认只存浏览器 localStorage，可选同步到自己的私有仓库。

**在线使用**：https://zhshy.github.io/tcm-workbench/

## 两个交付形态

1. **静态站（本仓库）**：`index.html`，离线可用，可「添加到主屏幕」。数据存浏览器，可选同步到私有仓库。
2. **资料库数据页**：`library-page/index.html` 存档，线上版本 https://workbuddy.link/p/alkYf196OwOYNtXaTQoV9E 。数据存资料库三张表（任务节点 / 每日打卡 / 专注记录），跨设备登录即同步。该存档依赖资料库运行环境，脱离后只显示静态壳。

## 168 天课程：四个阶段走完一遍

课程按四阶段编排，正好覆盖路线图的 24 周，每天一课，单课 **45–48 分钟**：

| 阶段 | 天数 | 内容 |
| --- | --- | --- |
| 1 骨架 | D01–D49 | 中基 + 中诊：绪论与阴阳五行、藏象、气血津液、经络、病因病机、四诊、八纲 |
| 2 血肉 | D50–D105 | 中药 + 方剂：中药总论与各类药、方剂总论与各类方、闭卷方解复盘 |
| 3 溯源 | D106–D147 | 经典原文校读：伤寒论六经条文、金匮选篇、内经选篇、温病条辨选读 |
| 4 输出 | D148–D168 | 四个专题 + 成文与自检：桂枝汤类方互见、证症候词义、阳气义项、版本异文 |

- **543 段经典原文**，每课 3–4 段，每段四层：原文 / 出处 / 白话 / 看这里（句读、训诂或异文提示）。阶段 3、4 的原文全部是条文校读材料，`tip` 里写明关键字读法与「异文待核」的边界，**不编造异文**。
- **672 道客观题**（168 × 4），单选 / 多选 / 判断；提交后才给答案与解析，解析点明错误项错在哪；多选漏选判错，可无限重做。
- **时长**：3 段原文 45 分钟（129 天），4 段 48 分钟（39 天），合计 7677 分钟 ≈ 128 小时，日均 45.7 分钟。
- **解锁规则**：开始日取第一次打开那天，第 N 天只在第 N 天解锁，未来日期是锁定态、点不开；提交练习才算完成一天，重做不重复计时长。
- **联动**：完成一课即把该课时长计入当日学习，并自动生成 D+3～D+5 的学情检查（全部客观题）。

旧版「96 天 · 每天 20 分钟」保留为 [v1-96天版.html](v1-96天版.html)，数据在 `data/plan.json`。

### 手机和电脑的数据怎么同步

静态站默认把数据存在各设备浏览器本地。要跨设备长期沉淀，用**笔记库**：把数据写进自己的 GitHub **私有**仓库，Git 历史即版本历史。

配置方式：「笔记库」页 → 填 `owner/repo`（默认 `zhshy/tcm-notes`）与令牌 → 保存并连接。令牌建议用 **fine-grained token**，只授予该仓库 `Contents: Read and write`。

没有令牌时，也可以用两种手动方式搬运：

1. **同步码**：「我的卡片 → 跨设备同步 → 生成同步码」，把文本发到微信/备忘录，另一台粘贴导入。
2. **JSON 备份**：导出文件后传到另一台设备导入。

导入会覆盖本机数据，操作前先导出备份。

## 本地开发

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

直接双击 `index.html` 也能用（`file://` 下卡片与进度正常）。

## 更新与提交

```bash
# 推送（本机 git 协议不可用，走 Git Data API）
GH_TOKEN=<你的 token> python3 tools/push_to_github.py

# 自定义提交信息
GH_TOKEN=<你的 token> python3 tools/push_to_github.py --message "feat: 更新第 5 周内容"
```

脚本分三步：按 blob SHA 差分只传变更文件 → 建 tree/commit/ref → 推完重新拉取远端树逐文件回验。
